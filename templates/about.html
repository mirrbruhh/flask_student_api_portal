ABOUT THIS PROJECT

This portal was built to bridge the gap between basic Flask routing and actual production deployment. Instead of just accepting any data, the backend actively filters, limits, and manages what comes in.

Here are the key security and lifecycle features I added to the original challenge:

  • Rate Limiting: Caps form submissions and API requests to 5 per hour to prevent endpoint spam.
  • Auto-Cleanup: Uses MongoDB TTL indexes to automatically delete student and feedback records after 30 days.
  • Content Filters: Runs backend regex and profanity checks to block promotional links and inappropriate language.
  • Bot Protection: Uses a hidden CSS honeypot field to quietly trap and reject automated scraping bots.
